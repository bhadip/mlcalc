# Archived Components

This directory contains deprecated React components that are no longer used in the application.

## Contents

- `SimulationPanel.tsx` - Replaced by `Calculator/Calculator.tsx`
- `MarginLevelGauge.tsx` - Replaced by `Calculator/MarginGauge.tsx`
- `StopOutAlert.tsx` - Replaced by `Calculator/StopOutAlert.tsx`

## Why Archived?

These components were part of the initial implementation but have been superseded by the new Calculator component structure which provides:
- Better organization
- Improved UX
- Cleaner code structure
- More maintainable architecture

## Note

Do not use these components in new development. Refer to the `Calculator/` directory for current implementations.
